# PetRWKV 架构设计文档

## 1. 系统概述

PetRWKV 是一个本地智能宠物应用，核心特性是**可进化**——通过与用户的日常对话，在设备端自动微调 RWKV-v7 模型，实现个性化成长。

### 1.1 设计原则

- **完全本地**：推理、训练、存储全部在设备端，零云端依赖
- **隐私优先**：对话数据永不离开设备
- **渐进进化**：宠物能力随使用时间逐步提升
- **资源友好**：训练仅在充电/闲置时进行，不影响正常使用

## 3. 模块详解

### 3.1 RWKV 推理引擎

基于 `rwkv-mobile` 的 C++ 推理引擎，通过 FFI 暴露给 Dart 层。

**关键设计**：
- 支持多后端自动选择（NPU > GPU > CPU）
- 原生集成多模态编码器，无需外挂
- 支持 LoRA 热更新，训练后立即可用

### 3.2 RAG 记忆系统

本地向量检索 + SQLite 存储，实现长期记忆。

**数据流**：
```
对话 → 重要性评估 → 嵌入提取 → SQLite 存储
                          ↓
查询 → 嵌入提取 → 余弦相似度检索 → 返回相关记忆
```

**重要性评估规则**：
- 包含关键词（喜欢/讨厌/重要/记住）+0.2
- 长度 > 100 字符 +0.1
- 包含问号 +0.05
- 基础分 0.5

### 3.3 训练管线

设备端 LoRA 微调，基于对话历史构建数据集。

**训练流程**：
1. 充电/闲置检测触发
2. 获取最近 100 条对话
3. 筛选重要性 >= 0.6 的对话
4. 构建 instruction/output 对
5. 执行 LoRA 微调（r=8, alpha=16）
6. 更新宠物状态和经验值

### 3.4 宠物进化系统

5 阶段进化，基于累计训练天数：

| 阶段 | 名称 | 条件 | 能力 |
|------|------|------|------|
| 🥚 Lv.0 | 神秘蛋 | 初始 | 基础对话 |
| 🐣 Lv.1 | 幼崽 | 1 天训练 | 记住偏好 |
| 🐥 Lv.2 | 少年 | 7 天训练 | 图片理解 |
| 🦊 Lv.3 | 成年 | 30 天训练 | 音频理解 |
| 🐉 Lv.4 | 传说 | 90 天训练 | 视频理解 + 完整人格 |

### 3.5 后台调度器

监听设备状态，智能触发训练：

- **充电状态**：立即触发训练
- **闲置 10 分钟**：触发训练
- **低电量**：暂停训练
- **用户活跃**：暂停训练

## 5. 性能优化

### 5.1 推理优化

- **量化支持**：INT8/INT4 量化，降低内存占用
- **KV Cache**：复用历史状态，加速多轮对话
- **批处理**：多模态输入并行编码

### 5.2 训练优化

- **梯度累积**：batch_size=4, accumulate=4，等效 batch=16
- **混合精度**：FP16 训练，降低显存占用
- **早停策略**：val_loss 连续 3 轮不下降则停止

### 5.3 存储优化

- **记忆清理**：30 天后自动清理 importance < 0.3 的记忆
- **模型压缩**：LoRA 权重合并到基础模型后压缩
- **增量备份**：只备份变化的数据

## 6. 安全与隐私

- **零云端依赖**：所有数据本地处理
- **加密存储**：SQLite 数据库加密
- **权限最小化**：仅请求必要权限
- **透明日志**：用户可查看训练记录
